# VCF reporting on abdominopelvic CT: reproducible statistical analysis

Code supporting the multicenter retrospective cohort study of vertebral compression fracture reporting, subsequent fractures, and clinical care. This repository contains analysis code and aggregate reference estimates, **not patient-level study data** or the commercial screening software.

## Scope

* Table 1: means, sample standard deviations, counts and percentages, including follow-up months.
* Tables 2–3: primary Firth logistic models for two outcomes, pooled and separately in each center (six models).
* Table 4: six full-adjustment Firth models and two pooled models excluding prior fracture-related procedures.
* Pooled standardized adjusted probabilities and risk differences from maximum-likelihood logistic regression, with 2,000 center-by-reporting-stratified patient bootstrap replicates per outcome.
* Figure 4: forest plot of the six primary Firth estimates.

Figure 1 is a cohort flow diagram and Figures 2–3 are clinical images. They are not generated by these statistical scripts. Historical exploratory analyses not reported in the final manuscript are outside this package.

## Setup and execution

Validated environment: R 4.6.1, logistf 1.26.1. The complete installed package inventory is in `environment_versions.csv`. Base R handles data input, summaries, bootstrap and plotting. No Python is required.

Install `logistf` and its dependencies in your R library. For the validated direct dependency version, use `remotes::install_version("logistf", version="1.26.1", repos="https://cloud.r-project.org")` after installing `remotes`. Compare dependency versions with the inventory when exact numerical reproduction is required. This is a version inventory, not a dependency lockfile.

Run from the repository root:

```sh
Rscript run_all.R /path/outside/repository/analysis.csv /path/outside/repository/results 2000
```

The output directory must not already exist. For a synthetic-data smoke test:

```sh
Rscript run_all.R data/example_synthetic.csv /path/to/new/demo_results 20
```

The example data are wholly simulated and do not reproduce the manuscript results. Twenty resamples are for testing execution only, not inference. The published analysis uses 2,000 replicates per outcome. Plotting uses Cairo and Times New Roman where available. Font availability may affect appearance across platforms without changing the numerical estimates.

## Input and variable definitions

See `data/data_dictionary.csv`. One row represents one patient. Preserve the original study row order for exact bootstrap replication. Do not provide identifiers or dates. This code starts from the curated analytic cohort, after image review, eligibility assessment, and EMR extraction. It does not repeat clinical adjudication or infer eligibility from raw records.

Center 1 is Gangnam and Center 2 is Sinchon. The model reference is Center 2, preserving the original factor order. Reporting is numeric 0/1, with unreported as reference. Prior procedures are present for original codes 1/3 and absent for 0/2. The care composite is positive when either clinic attendance or qualifying new medication is recorded within 90 days, with each patient counted once. Baseline and outcome medication definitions follow Supplementary Table S1, including calcium/vitamin D. Follow-up months retain the adjudicated recorded duration, rather than being recomputed from imprecise dates.

The pipeline requires complete data and stops on missing or invalid input. In the actual analytic cohort, all 286 patients had complete modeled data. No imputation is performed.

## Statistical details

Primary models include age, sex, BMI, moderate and severe fracture counts, prior procedure status, and center for pooled models. Center-specific models omit center. Full models additionally include hypertension, diabetes mellitus and chronic kidney disease. Restricted pooled models exclude prior-procedure patients and omit procedure status.

All 14 OR models use Firth penalized logistic regression (`logistf`, `pl=TRUE`), profile penalized-likelihood confidence intervals for the reporting coefficient, and raw two-sided penalized likelihood-ratio P values. No BH adjustment is applied. Sparse cells, EPV below 10, warnings and convergence measures are exported for inspection. EPV here uses the smaller binary outcome count divided by the number of non-intercept coefficients.

Adjusted probabilities use conventional maximum-likelihood logistic regression with the primary covariates, not Firth probabilities. Each patient's reporting value is set to 0 and 1 and predictions are averaged. Risk difference is reported minus unreported. The bootstrap samples patients with replacement within center-by-reporting strata, refits the model, and standardizes within the resampled dataset. Seed 42 is set once before the two outcomes. RNG settings and outcome/stratum order are fixed. Percentile limits use R's default quantile type 7. Failed/nonfinite/rank-deficient replicates are flagged and excluded. The pipeline stops if at least 5% are invalid. Inspect diagnostics even when it completes.

These probabilities describe the selected analytic sample. They are not population incidence estimates, exact five-year cumulative incidence, or causal effects. Risk ratios and bootstrap OR draws are auxiliary diagnostic outputs, not additional reported primary estimands.

## Reproduction checks

`reference_results/firth_estimates.csv` combines the original primary/restricted Firth estimates with the updated October 11 full-model results. `reference_results/adjusted_risks.csv` contains the original marginal-standardization results. The follow-up reference is retained for cross-checking descriptive summaries.

After a run on the authorized study data:

```sh
Rscript verify_results.R /path/to/results
```

This compares all 14 ORs, CIs and P values, and all adjusted probability/difference/ratio estimates and CIs against aggregate reference outputs. It is expected to fail for synthetic data. See `VALIDATION.md` for the private-data reproduction report. No saved fitted models are needed or distributed.

## Data access and public release

Patient-level study data are not included. Requests should follow the manuscript's data sharing statement and institutional requirements. The code cannot reproduce actual study estimates without authorized access to the study data. The commercial AI screening system is not distributed here.

Do not upload the parent project, private CSVs, saved R model objects, clinical images, or generated patient-level files. `.gitignore` is a precaution and does not replace reviewing the files selected for release. A software license has not been selected on behalf of the authors. Choose a license with the authors before public release if reuse permission is intended.
